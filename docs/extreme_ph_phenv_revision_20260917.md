## 1. 已验证事实与需要收窄的结论

| 原判断 | 复核结果及对设计的影响 |
|---|---|
| 完整模型受凸组合上限约束，仿射外推是唯一可行方向 | `phgeofuse/model.py:375` 的确是凸组合，只能在**当前样本、固定专家值**的范围内融合。但 `phgeofuse/delta_ref/baseline.py:223–253` 的完整基线还含 Ridge 和可加 GBDT 残差；重训也能改变专家值。测试最大值约 9.55 是行为证据，不是整个模型的数学上限。 |
| 可直接复用 homology_residual 来外推 | 该模式在 softmax 之前修正的是门控 logits，仍是凸组合。可借鉴零初始化、基线保护和交叉拟合的工程方式；新残差必须在最终连续 pH 输出之后相加。 |
| 官方 sample_weight 从未进入任何拟合 | `io.py` 解析权重，`dataset.py` 传到 batch，`compute_loss` 的分布项已使用裁剪后的官方权重。遗漏的是主 MSE 与低同源视图 MSE；完整系统若干支路也使用重算的频率权重。 |
| 极端端仅获得 2.64%/1.35% 的实际梯度或损失 | 这类数值是按样本权重与名义系数推算的质量，不是实际梯度或损失贡献；后者还取决于各样本误差、NLL 和梯度。新实验需分别记录逐区间 MSE/NLL/加权贡献。 |
| AUC 0.64 证明冻结表征无可用信号 | 原探针是 pooled ESM→PCA192→逻辑回归，且 PCA 在所有开发折上拟合，属于使用留出协变量的变换。只能说明该管线的排序能力弱。严格对照需折内拟合变换，并同时报告 AP、正例比例和家族不确定性；它不能否定所有残基层表征。 |
| 斜率 1.0014 证明完全校准、任何事后修正必败 | 全局线性斜率不等于完整条件均值校准。即便 E[y\|y0]=y0，新增序列信息仍可能使 E[y\|y0,z] 不同。已有负结果支持停止无依据的全局拉伸，不构成整类条件残差的不可行证明。 |
| n=22 存在固定 0.65 的改善检测下限 | `tmp/diag_power.py` 实际按样本重采样，并把单模型区间宽度用作比较阈值。配对比较取决于两模型误差差值及协方差，没有这个固定下限。22 条仍很脆弱，应报告实际家族数、配对区间和独立确认结果。 |

碱端 bias²/MSE 很高说明误差以平均低估为主；它没有区分信息不足、训练目标、正则化与输出结构等原因。按真实标签定义的尾部也不能在推理时直接识别。

训练 manifest 复核：7124 条中，官方权重 0.366 对应 6505 条、标签 5.0–8.95；8.599 对应 285 条、1.0–4.9；6.531 对应 334 条、9.0–12.0。它们对应较宽的酸/中/碱区间，不等于本项目的 pH≤4、pH≥10。官方权重的计算数据范围尚未确认，严格交叉验证的主对照应在各训练子集重算权重。

OpHReda 仍只列作公开结果参考：其分类加连续校准的结构有效允许连续输出，但外部 augmentation/database 的信息条件未完成审计。不能把公开成绩直接作为受控领先门槛。pI 的文献负结果支持不优先重复 pI 单变量路线，不是否定所有条件性局部电荷信息的数学证明。

## 3. pHenv 能提供什么

已核查的 EpHod 原文归档报告：用约 190 万条分泌细菌蛋白对应的来源生物最适生长 pH 预训练，再迁移到 pHopt；同结构的无预训练对照 EpHod-np 较差。这是采用辅助任务的依据，不是本候选已经有效的证据。

- **任务有关联但不相同。** 分泌蛋白暴露于外界环境，有迁移的生物学依据；胞内稳态、胞器、盐度、培养条件和催化机制会削弱或改变关联。禁止把 pHenv 与 pHopt 合并到同一个标签列，也不直接平均两个任务的预测。
- **序列数不等于独立标签数。** 原文在数据收集阶段从 3715 个来源生物取得序列，再筛选分泌蛋白。大量蛋白共享生物来源及生长 pH，不能视为 190 万次独立酶活测定，更不能称为 3 万倍的极碱监督证据。
- **原始隔离需要复核。** 原文报告按 20% identity 聚类、移除与原 pHopt 测试簇重叠的 pHenv 训练序列。这不自动保护本仓库的全部外层开发折及当前文件版本，也不能替代实际 identity/coverage 审计。
- **pHenv 是监督迁移，ESM 本体可先保持冻结。** 不需要先启动 ΔRef LoRA。更多辅助标签可能帮助小网络找到冻结表征中原来没学稳的方向，但不会凭空创造不存在于输入中的信息。

UniProt 的 Alkaliphilic/Acidophilic 注释数量只说明注释覆盖，不是连续生长 pH 或酶最适 pH 标签。先采用有标签来源和数值定义的 pHenv。

## 4. 推荐候选：环境监督的低维表征 + 有符号输出残差

设 y0(x) 为冻结的**完整基线**，h_j(x) 为冻结 ESM1v 残基表征。候选的初始具体设计是：

```text
残基 h_j → 无可训练仿射的 LayerNorm → 共享 1280→32 映射 → GELU
        → 有效残基的 mean/std → z(x)，共 64 维

pHenv 阶段：z(x) → 独立的生长 pH 回归头
pHopt 阶段：z(x) → a(x), b(x)
             y_hat = y0(x) + b(x) + a(x) * (y0(x) - 7)
```

这里 7 只是预先固定的数值中心，不是生化平衡约束。a、b 为线性头，权重及偏置全部零初始化；没有 softmax 凸组合、尾部阈值门控或按真实标签决定的推理分支。最终任务头只有 130 个参数，输出修正在 pH 单位中可以为正或负。先把环境表征冻结，再训练这个头；是否解冻只作为预先声明的额外对照。

该设计将几个问题分开处理：环境阶段用较多的辅助监督学习表示；酶阶段用低容量头限制 63 条极碱标签驱动的参数拟合；输出残差提供超出基线预测的自由度。三者都需要实验验证。

**零初始化只保证初始预测等于基线，不保证训练后中心不变。** 训练时增加中心修正惩罚：

```text
L = weighted_MSE(y_hat, y)
  + lambda_core * mean[(y_hat-y0)^2, for training rows with 4<y<10]
  + lambda_head * ||theta_head||^2
```

真实中心标签只用于当前训练子集的损失，推理不需要它。中心惩罚、早停和所有超参数只在内层开发；是否保持性能由外层中心/整体指标决定。不能把训练惩罚叫作对未见中心样本的数学保证。原模型的 preservation_mask 按同源性或全体样本定义，不能不加区分地当成中心区保护。

y0 的训练目标必须来自家族排除后的交叉拟合，不能用已见过该样本标签或近同源参考的训练内基线预测。拟合输出残差时，完整基线、检索库和其元模型都必须排除当前查询家族。复用既有 exclusion 缓存前验证来源；修改基线损失后必须新建对应缓存。

过拟合验证同时报告训练/家族留出 RMSE、两端误差、种子波动、参数量和辅助任务来源生物分组结果。训练误差变高或训练/验证间隙缩小，本身不是泛化改善。

## 5. 损失对照与有限迭代

先做便宜的正确性修正，再为辅助任务投入大规模编码；pHenv 数据审计可以同时准备。

1. **评估冻结。** 保留当前外层家族划分、参考源和既有内部门槛。修正探针时 PCA/标准化均在训练折拟合。原始验证/测试不参与本轮配方或阈值选择。
2. **原模型主 MSE 权重对照。** 为 normal 和 low_homology MSE 同时提供可配置的加权选项，保留未加权报告值；不是只改 distribution。严格主对照按当前拟合子集的 `<5 / [5,9) / ≥9` 三桶计数重算、均值归一。完整逆频率可能损害自然分布性能，可先声明一个温和混合权重方案；禁止见外层分数后不停调整。发布方原始权重另列复现对照并注明来源范围尚待核验。
3. **输出残差对照。** 同一表征/损失下比较加性 b(x) 与仿射 b(x)+a(x)(y0-7)。不扫描大量预测阈值。已有残差负结果作为背景保留。
4. **环境迁移。** 数据审核后，先用按来源生物/家族抽样的小规模数据验证训练管线和迁移信号，再决定是否扩展到全量。必须同时有同结构的 PHOPT-only、环境预训练后同样微调、环境预训练后冻结表征三个控制。仅和冻结随机编码器比较，不能证明有意义的预训练收益。
5. **Balanced MSE 单独比较。** 它改变回归目标的标签分布校正，不是普通加权 MSE 的另一个名字；其噪声尺度和标签密度/参考标签仅来自当前训练子集。先与加权 MSE 单独比较，不一开始叠加官方权重、重采样、Balanced MSE 和输出拉伸。

需要辨别的效应是：权重、输出形式、辅助监督、是否冻结。每个成对对照只改变相应因素；共享 PLM、池化、参考源、划分和预声明种子。先用 seed42 的开发小试验排除明显无效方案；只有候选达标再做固定方案的 seeds 0–4，每个种子都有匹配基线。实际早停轮数与参数量均保存，不把不同训练策略称为严格容量匹配。

加权 MSE 的最优条件均值一般变为 E[w(y)y|x]/E[w(y)|x]，不再是原分布的 E[y|x]。所以“修权重”不等于“无代价改善全部区间”；这正是保留未加权全体和中心指标的原因。

建议保留发布方原文件为 `data/phenv/pHenv_data.csv`。仓库目前没有发现该数据文件；仅放入目录不会自动进入现有训练。兼容字段为：

```text
Accession,Organism,Sample Weight,pHenv,Split,Sequence
```

建议同时保留 taxon_id、菌株/生长条件、原标签文献或数据库记录、分泌/定位证据及源文件校验和。已有邻近 EpHod 仓库的 `scripts/prepare_phenv.py` 可参考字段和数值校验，但不能把其数据准备通过等同于本项目的跨任务隔离通过。

接入时需形成独立 manifest，记录原始行号、序列 SHA256、来源生物组、同源组、标签来源、原始 Split、最终用途和每条排除原因：

- 检查缺失/非有限 pH、异常序列、重复和同序列冲突标签；保留冲突证据，不能随机丢弃不利标签。保留未裁剪序列并记录任何编码长度策略。
- 按来源生物与同源关系建立 pHenv 开发隔离；若联合分组产生巨型连通组，应报告组大小及被排除覆盖，不能为得到好指标拆开关联组。分组评估和训练中限制同一菌株的重复贡献，防止把蛋白数当作生物测量数。

- 若上述策略删除过多，则另立“逐折排除留出序列”的协议，每折独立准备环境数据和预训练；不能在看到成绩后把两种信息条件混在一起。最终测试近邻隔离一直生效。
- 原始官方 Split、严格新 Split 的记录数与来源生物/极端标签覆盖分别报告。声明对细菌分泌蛋白、胞内酶和其他来源的适用范围，检查迁移收益是否仅来自某些菌种或定位类别。

## 7. 评估口径和成功标准

主口径仍为原分布、未加权的整体/中心/极酸≤4/极碱≥10 RMSE、MAE、偏差与中心假极端率；保留酸碱两端，不用改善酸端掩盖碱端恶化。既有开发门槛仍是整体/中心 RMSE、MAE 最多 +0.01、假极端率最多 +0.005、两端 RMSE/MAE 至少改善 10%、绝对偏差至少改善 20%。它只是筛选门槛，不等于用户要求的整体性能不下降或领域领先。

最终冻结比较另要求整体和中心的点估计不劣，并报告配对家族区间；区间无法支持不劣时写“证据不足”，不事后放宽容差。领先还需同信息条件下的领域强基线，以及未用于方案选择的独立家族/极端富集确认集。不能把已选模验证集与测试集拼接成新的独立测试集。

次口径可报告较宽 `<5 / [5,9] / >9` 三段的等质量指标、分类 precision/recall/F1、AP 与基率。三段等质量 RMSE 定义为 sqrt((MSE酸+MSE中+MSE碱)/3)，不是三段 RMSE 的算术平均。它可由加权或有放回重采样估计，不要求每段都有 657 条独立样本；但重采样不增加独立证据。边界归属和官方指标复现应单独核对，不能冒称与论文所有 headline 数字相同。

家族 bootstrap 用同一组重采样索引配对所有模型与匹配种子，比较指标差值。当前 `phgeofuse/delta_ref/metrics.py::paired_family_bootstrap` 已实现全体/两端比较与多重比较区间；它移除了 core，若用于中心不劣确认需要补充中心端点。样本 RMSE 区间宽度不作为最小可检测改善。实际极端家族数、无极端样本的抽样次数和有效抽样数均需报告。

“中心完全不动则修好尾部可降低整体 MSE”的算术成立，但中心身份只在评估时已知；它不提供可实现的推理选择器。全局线性拉伸、按测试标签选阈值、放宽门槛凑通过、仅凭输出超过 10 宣称解决收缩，均不进入新一轮搜索。

## 8. 架构差异与算力边界

此候选不采用 EpHod 的 RLAT 残差轻注意力、OpHReda 的检索标签注意力与分类校准、EnzOracle 的类别 MoE、Venus-DREAM 的支持集适配或原子电荷等变图作为新分支。核心是小型共享残基映射、固定矩统计和环境监督约束的连续残差；最终仍使用原完整基线，必须披露其结构/检索信息。

**pHenv 预训练本身已有 EpHod 先例，零初始化、矩池化、仿射残差及 Balanced MSE 也不是新的技术。** 这份结构设计避免直接复刻上述主干，不能据此宣布原创性已成立。可检验的研究贡献应是跨任务转移、中心保持和极端泛化的组合及实证；若收益仅来自同一数据上的常规迁移，应如实降低创新表述。

先以小批真实长度分布测量 ESM 编码吞吐、显存、缓存体积和环境训练每轮时间，再给全量算力估算。冻结 PLM 仍有编码成本：若 190 万序列平均长度为 400，仅 fp16 的 1280 维全残基缓存约需 1.95 TB（十进制示例，非实测长度）。禁止直接启动全量本地缓存；考虑集群分片编码/训练与限定保留范围。

小试验由 `scripts/run_bounded_local.py` 对整个进程组限时，通常 30–60 分钟；任何本机任务硬上限不超过 9.5 小时。预测超预算的全量编码、预训练或逐折辅助预训练应提供实际 profile、存储与 GPU 需求及集群任务包后交由用户运行，不通过连续自动重启规避限制。ΔRef LoRA 不在本轮候选中。
