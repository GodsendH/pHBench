# IonContext-pH：局部可电离残基信息的低成本试验

2026-09-17。当前是研究候选，不替换默认预测器。ΔRef 冻结表征五折失败之后，用户明确暂不运行其 LoRA 嵌套训练；本轮不安排该任务。

## 假设与设计

完整蛋白的均值/标准差会丢失“某类可电离残基位于什么序列环境”这一对应关系。新增支路使用已经认证的 ESM1v 全残基缓存，剔除 BOS/EOS，按 D/E/H/C/K/R/Y 分组。固定、无标签的 64 维正交随机投影后，对每组计算：组内均值相对全蛋白的差、组内标准差、9 残基窗口均值相对中心残基的差，另加频率和存在标记，共 1358 维。窗口在末端只统计真实残基；缺失残基类型设零并显式标记。

这些是序列上下文，不是测得的 pKa、催化位点或空间邻域。全局平移和序列翻转检查只用于核验该池化的数学性质，不意味着蛋白功能对序列翻转不变。

训练子集独立拟合标准化，设置方差下限与截断。使用全局 ESM1v+ESM2 表征核和局部上下文核的加和，求解有正则的加权 Ridge。模型没有深层任务头、成对标签扩增、类别专家路由或检索标签注意力。减少可训练容量、闭式求解和显式正则是减轻过拟合的设计动机；是否有效必须依据相同家族留出误差及训练差距共同判断。

## 冻结的本轮开发协议

- 原始 PHOPT 训练集 7124 条，使用已审计的 3186 家族、五折划分。原始验证和测试分数不参与本脚本选择。
- 外层五折、内部四折。每个排除集合重训新支路，独立拟合标准化；完整基线预测复用已有同排除集合重训缓存，核验输入哈希、训练标签哈希、训练/查询键和家族隔离。
- 局部核权重 `0 / 0.5 / 2`，Ridge 正则 `0.2 / 2`，频率权重指数 `0 / 0.5`（权重上限 3），共 12 个配方。权重零是同表征、同选择程序的全局对照。
- 每个外层内部选择配方及与完整基线的融合强度 `0 / 0.25 / 0.5 / 0.75 / 1`。整体/中心 RMSE 和 MAE 增幅不得超过 0.01、中心错误极端率增幅不得超过 0.005；满足后最小化两端相对 RMSE 较大者，并列优先更小融合强度。
- 酸端为 pH≤4，碱端为 pH≥10。沿用内部筛选门槛：两端 RMSE/MAE 至少改善 10%，绝对平均偏差至少改善 20%。+0.01 是开发筛选容差，不能被表述为严格“性能不变”；最终还要核验原始 PHOPT 性能、五种子完整系统和同信息条件领域对照。
- 报告全部配方、内层选择、训练误差、完整外层预测、10000 次配对家族 bootstrap。Ridge 与固定投影是确定性的，不把复制五份结果当成五次独立训练。
- 已多轮查看的开发折和历史 PHOPT 测试不能作为全新独立外部验证；当前一切选择属于探索性研究。

## 与已核查领域模型的设计关系

依据仓库已有的论文与官方源码审计：EpHod 的 RLAT 使用残差轻注意力，Venus-DREAM 使用支持集内循环适配，OpHReda 使用检索标签注意力，EnzOracle 使用分类引导多专家，pHoptNN 使用原子电荷等变图。新增支路未复制这些核心结构；它以固定化学分组的残基环境统计与正则核求解为主。预训练编码器、Ridge、池化等均是已有通用方法，不能据此宣称全领域首次。需通过全局对照和额外独立证据才讨论局部表征的贡献。完整融合路径仍包含原有 PHGeoFuse 基线，论文描述必须如实保留这一点。

## 运行和本机边界

所有本轮实际计算在 WSL 的 `phbench` 环境运行。独立监督器 `scripts/run_bounded_local.py` 对整个进程组计时并强制终止，最多允许 9.5 小时；本轮特征缓存限 30 分钟、资源探针限 6 分钟、完整嵌套试验限 54 分钟、旧消融续跑限 45 分钟。达到限时保留已有产物，不自动无限续跑同一长任务。

```bash
cd /home/hetianci/projects/Venus-DREAM
conda activate phbench
python -B -m unittest discover -s tests -p 'test_localph.py' -v
python -B -m unittest discover -s tests -p 'test_bounded_local.py' -v
```

产物：`experiments/ion_context_phopt_20260917/`。`features_train/complete.json` 绑定全部源 token 哈希；`nested/protocol.json` 冻结模型配方及输入/源码/基线缓存哈希；`nested/excluded_*/` 保存每次训练的资源、训练和留出指标；`nested/predictions.csv` 和 `nested/results.json` 保存最终开发结果。异常资源探针的日志单独保留，不冒充训练结果。

旧消融安全续跑入口是 `scripts/continue_delta_ref_controls.py`，仅调用经典对照和消融函数，代码中没有进入 LoRA 的调用。原始 `python -m phgeofuse.delta_ref run` 仍是历史完整协议入口，可能自动触发多日 LoRA，因此本轮不使用它。

## 已完成结果与后续分支

完整报告：`experiments/extreme_ph_iteration_20260917/REPORT_ZH.md`。本轮候选均未达到双端验收，默认模型未替换，目标尚未完成。

1. 原ΔRef的全部剩余消融已完成并独立复算，LoRA保持用户要求的暂停状态。
2. 局部上下文绝对回归：180次拟合、约6.6分钟；整体RMSE 0.891504，差于同折完整基线0.889116，两端也未改善。
3. EnzyBase12k额外监督：匹配精度的全局/局部表征、正则来源偏移和仅PHOPT对照；360次拟合、约15分钟。原始公开表11615条经accession、序列、截短域和同源过滤后留下1119条（极酸27、极碱16）；启发式检索不能保证发现所有同源。完整来源校正候选RMSE 0.893747，未通过双端验收。
4. 完整基线折外残差回归：40次拟合、约2.3分钟；16个固定配方全部保留。部分配方整体轻微改善，双端幅度仍不足；事后最佳行不是独立确认。
5. 连续pH条件密度：24个余弦矩、Gaussian频谱平滑、可选训练边缘先验校正、均值/峰值决策；5×4完整分组选择，30次矩回归、约1.1分钟，五外层全部选择零修正。密度不当作校准置信区间或物理活性曲线。

新增实现位于`localph/`，不改动冻结的历史`phgeofuse`代码。对应入口为`evaluate_external_context.py`、`evaluate_crossfit_context_residual.py`、`evaluate_ph_density.py`。外部监督实验在报告中明确区分训练条件，没有作为PHOPT-only结果列示。16项新增行为测试通过，所有实际启动的任务均正常结束，最长约21分钟。

后续工作应基于这些失败证据重新选择表征/监督路径，不把开发折反复选择后的最佳行宣称为极端领先。仍须满足原PHOPT性能、真实两端指标、过拟合诊断与领域受控对照；未达标不得解除发布门槛。
